## 🎮 About This Project

Atlas VR is an immersive virtual reality experience developed in Unity. This project showcases advanced VR interaction mechanics, including gesture recognition and physics-based object manipulation. The game is set in a sci-fi environment and features a variety of interactive elements designed to create a deeply engaging player experience.

This project is a portfolio piece demonstrating expertise in Unity development, C# programming, and VR interaction design.

## ✨ Key Features

*   **Advanced Gesture Recognition:** The game recognizes a variety of hand gestures, including:
    *   Thumbs Up
    *   Wave
    *   Face Palm
    *   X-Arms
*   **Force Grab:** Players can use a "force grab" mechanic to interact with objects from a distance.
*   **Physics-Based Interactions:** Objects in the world are fully interactive and respond realistically to player actions.
*   **Immersive Sci-Fi Environment:** The game is set in a detailed sci-fi world, built with a combination of custom and pre-made assets.
*   **VR-Native Locomotion:** The project includes a robust and comfortable VR locomotion system.

## 🛠️ Technologies Used

*   **Game Engine:** Unity
*   **Programming Language:** C#
*   **VR Platform:** SteamVR / Oculus
*   **Core Libraries:**
    *   Unity XR Interaction Toolkit
    *   Unity Input System

## 🚀 Getting Started

To run this project, you will need:

*   Unity Hub
*   Unity 2022.3 or later
*   A VR headset (Oculus, Vive, etc.)

**To get started:**

1.  Clone this repository.
2.  Open the project in Unity Hub.
3.  Unity will automatically install the required packages.
4.  Open the main scene in `Assets/Scenes/`.
5.  Press "Play" to start the game in the Unity editor.
